# 레코드룸

내 노래를 **앨범 커버 · LP · 카세트테이프**로 틀어 주는 한 페이지 플레이어.

**열기**: https://toddoward.github.io/record-room/

## 할 수 있는 것

- 유튜브 영상 주소, **재생목록 주소 하나로 통째로**, MP3 파일(파일 안의 제목·가수·커버 그림을 읽는다)
- 화면 세 가지
  - **커버** — 커버 사진에서 색을 뽑아 화면 전체를 그 색으로 맞추고, 나머지 색은 배경에 은은하게 흐른다
  - **LP** — 판이 천천히 돌고, 재생하면 톤암이 판 위로, 멈추면 제자리로
  - **카세트** — 스티커에 커버 사진과 제목, 재생 시간에 따라 테이프 두께가 바뀌고 릴이 돈다
- 순서대로 / 섞어서, 반복 끔 / 전체 / 한 곡, 지금 섞기
- **움직이는 카드 저장** — 지금 화면을 4초짜리 WebP로(WebP를 만들 수 없는 브라우저 — 아이폰·아이패드 Safari 등 — 는 GIF), 휴대폰 공유 창으로 바로 보내기

## 알아 둘 것

- MP3·사진은 이 기기를 벗어나지 않는다. 유튜브 곡은 유튜브 삽입 플레이어로 재생한다
- 음원 영상 가운데 **"다른 사이트에서 재생"이 막힌 것**은 재생되지 않아 건너뛴다 (영상 주인이 정한 것 — 유튜브 프리미엄과 상관없음)
- 내 컴퓨터의 파일(`file://`)로 열면 유튜브가 재생을 막는다 — 위 주소로 연다
- 넣은 유튜브 곡 목록은 이 브라우저에 저장된다. MP3는 다시 열면 다시 넣어야 한다

## 만든 계기

커버 색을 뽑는 방식은 [trackpic](https://github.com/pic-kn/trackpic)과 같은 절차(가운데 70% · 중앙값 자르기 25색 · 주색에 가까운 색 · 밝기순 5색)를 다시 작성했고, LP 플레이어는 [캔따개 플레이리스트](https://github.com/dearlovedive/playlist)에서 영감을 받았다.
