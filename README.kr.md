# 레코드룸 (Record Room)

**내 노래를, 내 사진을 앨범 커버로, 커버 · LP · 카세트테이프 플레이어로.**

익숙하다 못해 질리는 스트리밍 앱 대신, 나만의 재생목록을 만들고 좋아하는 사진을 앨범 커버로 씌워 원하는 플레이어로 듣는 한 페이지 음악 플레이어. 듣고 있는 순간은 움직이는 카드로 저장할 수 있다.

## 핵심 가치

- **나만의 재생목록** — 유튜브 영상, 유튜브 재생목록 통째로, MP3 파일을 한 목록에
- **내 사진이 앨범 커버** — 어떤 사진이든 커버가 되고, 화면 전체가 그 사진의 색으로 물든다
- **나만의 재생 화면** — 커버 · 돌아가는 LP · 카세트테이프 중 골라서
- **순간을 저장** — 지금 화면을 4초짜리 움직이는 카드로 저장해 휴대폰에서 바로 공유

## 기능

### 1. 플레이어 세 가지

| 플레이어 | 화면 |
|---|---|
| **커버** | 커버에서 뽑은 색으로 화면 전체를 맞추고, 나머지 색은 배경에 은은하게 흐른다 |
| **LP** | 판이 돌고, 재생하면 톤암이 판 위로, 멈추면 제자리로 |
| **카세트** | 사진이 담긴 스티커와 사진 색의 레트로 띠, 릴이 돌고 재생 시간에 따라 테이프 두께가 바뀐다 |

### 2. 노래 넣기

- **유튜브 영상 주소** — 커버와 색은 영상 썸네일에서
- **유튜브 재생목록 주소** (`list=…`) — 주소 하나로 통째로 추가
- **MP3 파일** — 파일 안의 제목 · 가수 · 커버 그림을 읽는다

### 3. 내 커버 사진

- 사진을 올리거나 사진 주소를 넣으면 → **어떤 노래든** 그 사진이 커버, 색도 그 사진에서
- **＋** 창에 있고, 바꾸거나 **기본 커버로**를 누르기 전까지 유지

### 4. 움직이는 카드

- 지금 화면을 **4초짜리 움직이는 WebP**로 저장 (WebP를 만들 수 없는 브라우저 — 아이폰 · 아이패드 Safari 등 — 는 GIF)
- 카드에 조작 버튼을 넣을지 선택 (기본은 없음, 마지막 선택 기억)
- 휴대폰 공유 창으로 바로 보내거나 기기에 내려받기

### 5. 재생

- 순서대로 / 섞어서, 반복 끔 / 전체 / 한 곡, **지금 섞기**, 소리 크기
- 키보드: `Space` 재생 · 일시정지, `←` `→` 이전 · 다음 곡
- 휴대폰 잠금 화면에서 조작

## 바로 시작하기

1. **https://toddoward.github.io/record-room/** 열기 (또는 아래 QR을 휴대폰 카메라로)
2. 오른쪽 위 **＋** → 유튜브 주소 · 재생목록 주소 · MP3 파일 넣기
3. 위쪽에서 **커버 / LP / 테이프** 고르기, 원하면 ＋ 창에서 **내 커버 사진** 설정
4. **움직이는 카드 저장**으로 지금 순간 남기기

## 알아 둘 것

- **개인정보** — MP3와 올린 사진은 이 기기를 벗어나지 않는다
- **기억되는 것** — 넣은 유튜브 곡 · 내 커버 사진 · 설정은 이 브라우저에 저장. MP3는 다시 열면 다시 넣어야 한다
- **재생되지 않는 영상** — 영상 주인이 다른 사이트에서의 재생을 막은 영상은 건너뛴다
- **“… - Topic” 음원** — 유튜브 뮤직 자동 음원은 몇 초 뒤 멈추는 경우가 많다. 공식 뮤직비디오나 다른 업로드를 넣는다 (유튜브 프리미엄과 무관)
- **사진 주소로 커버 넣기** — 사진 서버가 다른 사이트의 읽기를 막으면 이미지 중계 서비스 [wsrv.nl](https://wsrv.nl)을 거쳐 가져온다 (그 사진 주소가 wsrv.nl에 전달된다)
- **웹 주소로 열기** — 내 컴퓨터의 파일(`file://`)로 열면 유튜브가 재생을 막는다

## 개발자용
